# 滴滴手沖 Drip Drip ☕

一款卡通風的手沖咖啡網頁小遊戲。你是咖啡店的實習咖啡師，臭臉貓店長「拿鐵」會全程盯著你，沖錯一步他就生氣來干擾。

## 怎麼玩

全程用手指（或滑鼠）操作，一局約 1–3 分鐘：

1. **選豆**：從 3D 豆子架上挑一袋：衣索比亞 耶加雪菲、巴拿馬 藝伎、哥倫比亞 薇拉
2. **選濾杯**：從 3D 展示架上挑一個：Hario V60、Kalita Wave、Chemex
3. **選沖法**：經典三段式、Hoffmann 一刀流、粕谷哲 4:6 法
4. **秤豆**：長按倒豆，越接近目標克數越好
5. **手磨**：先調研磨刻度，再繞著磨豆機畫圈，速度要穩
6. **濕濾紙**：繞濾紙一圈
7. **沖煮**：按住粉床出水、手指繞圈，照著每一段的水量和時間注水

沖完由店長評鑑：滿分 100、最高三星，附風味雷達圖，還可以把成績圖卡分享出去。27 種組合都有圖鑑紀錄。

## 在自己電腦上跑

不需要安裝任何東西，直接用瀏覽器打開 `index.html` 就能玩。

## 技術

純 HTML、CSS、JavaScript，沒有任何框架或建置步驟。圖都是用 SVG 和 Canvas 畫的。
